- **`POST /_mock/advance?to=<time>`** moves the clock forward to a moment
  instead of by a number of seconds ([#341]), releasing whatever falls due on
  the way exactly as `?seconds=` does for the same distance. The time is ISO
  8601 with a `Z` or an offset; one with neither is refused rather than
  guessed at, and a `+` must be written `%2B`, since a bare `+` in a query
  string means a space. A moment the clock is at or past is a 400 naming
  where it stands - it only goes forward - and so is `to` beside `seconds`,
  `?all` or `?failed`. The answer is the one `?seconds=` gives. It is for a
  script that walks several mocks to one moment, which had to work out
  mock-edi's distance on the client side alone; `mockedi.testing.Mock.advance`
  takes `to=` as well.
