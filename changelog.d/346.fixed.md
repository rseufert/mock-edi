- **A flag with a value it does not know is refused** ([#346]). `?all`,
  `?leave`, `?raw` and `?failed` are bare words, and `=1`, `=true` and `=yes`
  are still read as the word. Any other value was read as the flag being
  absent, so `POST /_mock/advance?all=false` was an advance of zero seconds
  that answered 200 and `GET /_mock/mailbox?leave=no` took the documents. It
  is now a 400 naming the flag, `=false`, `=0` and `=no` included: leave the
  flag out to not set it.
- **`/_mock/documents?acknowledged=` takes `true` or `false` and refuses
  anything else** ([#346]). `=false` is unchanged. `=maybe` and `=off` were
  read as `false`.
- **`/_mock/mailbox` reads its flags before it collects** ([#346]), so a
  request it refuses has taken nothing.
